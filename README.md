Planned repository for Corvin-original visual and audio assets consumed by [design-system](https://github.com/corvin-chess/design-system), [web](https://github.com/corvin-chess/web), and other clients: Corvid piece SVGs, Ravenboard colors, move/capture/check/game-end sounds, brand mark, and self-hosted IBM Plex font files. No piece SVGs, board art, sounds, brand files, or font files are in this repository yet. Everything chess-specific stays Corvin-original; no third-party piece sets, boards, or sounds.
